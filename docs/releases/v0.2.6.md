## English

Download **`photocraft-codex-ai-0.2.6-windows-x64-portable.zip`**, extract the entire archive into a writable folder, and double-click **`start.cmd`**. Save your documents and close the previous version before updating.

- Includes the matching PhotoCraft editor, Python 3.13.5, Pillow 11.3.0, and Codex CLI 0.166.0. No separate Python, Node.js, or Codex installation is required.
- Follow the first-run prompt to sign in with your own Codex/ChatGPT account. Internet access and an account with working built-in image generation are still required.
- Contains no account credentials, proxy configuration, or task history. See the bundled `使用说明.txt` for proxy setup.
- Edit selections, remove objects, and generate images from the in-editor toolbar. Results are imported as new layers with Ctrl+Z undo support.
- Image generation adds no extra feathering; selection edits and object removal default to 12 px.
- This legacy portable package bundles Codex; version 0.2.7 and later use local Node.js/Codex.

This is a Windows x64 preview development build. Internet access and a Codex account with working built-in image generation are required. GitHub's automatically generated Source code archives do not include the matching editor binary. See [VALIDATION.md](https://github.com/kaliwell/photocraft-codex-ai/blob/v0.2.6/VALIDATION.md) for recorded results and known boundaries.
