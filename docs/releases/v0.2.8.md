## English

Download **`photocraft-codex-ai-0.2.8-windows-x64-local-node.zip`**, extract the entire archive into a writable folder, and double-click **`start.cmd`**. Save your documents and close the previous version before updating.

- Fixes generated images failing to import when Windows refuses to launch a copy command.
- Receives the complete PNG directly from the current Codex session, without asking Codex to copy it through PowerShell.
- Reads complete PNGs only from the current session directory, without scanning historical sessions or reading arbitrary paths from prompts; preserves the existing sandbox settings.
- Uses local Node.js and npm-installed Codex CLI; includes the matching PhotoCraft editor, Python, and Pillow.
- Image generation adds no extra feathering; selection edits and object removal default to 12 px.

This is a Windows x64 preview development build. Internet access and a Codex account with working built-in image generation are required. GitHub's automatically generated Source code archives do not include the matching editor binary. See [VALIDATION.md](https://github.com/kaliwell/photocraft-codex-ai/blob/v0.2.8/VALIDATION.md) for recorded results and known boundaries.
