# PhotoCraft Codex AI v0.2.7 · 使用本机 Node.js / Use local Node.js

## 中文

下载 **`photocraft-codex-ai-0.2.7-windows-x64-local-node.zip`**，完整解压到可写目录后双击 **`start.cmd`**。更新前请先保存文档并关闭旧版窗口。

- 不再打包 Node.js 或 Codex CLI，改用电脑现有 Node.js 和通过 npm 安装的 Codex；支持自定义 npm 安装目录。
- 保留内置 Python、Pillow 和配套 PhotoCraft，无需另外安装 Python。
- 复用已有 Codex 登录；尚未登录时按提示登录自己的账号。
- 如已有 Node.js 但没有 Codex，先执行 `npm.cmd install -g @openai/codex`。
- 生成图片不额外羽化；局部修改和移除物体默认羽化 12 px。

这是 Windows x64 试用开发构建。需要网络和实际支持内置生图的 Codex 账号；GitHub 自动生成的 Source code 压缩包不含配套编辑器二进制。验证记录与已知边界见 [VALIDATION.md](https://github.com/kaliwell/photocraft-codex-ai/blob/v0.2.7/VALIDATION.md)。

## English

Download **`photocraft-codex-ai-0.2.7-windows-x64-local-node.zip`**, extract the entire archive into a writable folder, and double-click **`start.cmd`**. Save your documents and close the previous version before updating.

- Stops bundling Node.js and Codex CLI. Uses the computer's existing Node.js and npm-installed Codex, including custom npm installation prefixes.
- Keeps bundled Python, Pillow, and the matching PhotoCraft editor; a separate Python installation is unnecessary.
- Reuses an existing Codex sign-in, or prompts you to sign in with your own account.
- If Node.js is installed but Codex is missing, first run `npm.cmd install -g @openai/codex`.
- Image generation adds no extra feathering; selection edits and object removal default to 12 px.

This is a Windows x64 preview development build. Internet access and a Codex account with working built-in image generation are required. GitHub's automatically generated Source code archives do not include the matching editor binary. See [VALIDATION.md](https://github.com/kaliwell/photocraft-codex-ai/blob/v0.2.7/VALIDATION.md) for recorded results and known boundaries.
