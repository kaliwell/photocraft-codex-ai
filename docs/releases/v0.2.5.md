# PhotoCraft Codex AI v0.2.5 · 生成图片保留选区边缘 / Preserve selection edges for generation

## 中文

下载 **`photocraft-codex-ai-0.2.5.zip`**，完整解压到可写目录后双击 **`start.cmd`**。更新前请先保存文档并关闭旧版窗口。

- 在 PhotoCraft 编辑器选区下方直接使用局部修改、移除物体和生成图片。
- 生成图片取消额外边缘羽化，保留原始选区遮罩；局部修改和移除物体继续默认向内羽化 12 px。
- 支持为插件启动的 Codex 配置独立 HTTP 代理；使用 HTTPS 并限制连接重试。
- 生成结果添加为新图层，支持 Ctrl+Z 撤销。
- 此版本需要 Python 3.10+、Pillow（`pip install -r requirements.txt`），以及已安装并登录、实际支持内置生图的 Codex CLI。不需要 API Key，不自动切换付费 API。

这是 Windows x64 试用开发构建。需要网络和实际支持内置生图的 Codex 账号；GitHub 自动生成的 Source code 压缩包不含配套编辑器二进制。验证记录与已知边界见 [VALIDATION.md](https://github.com/kaliwell/photocraft-codex-ai/blob/v0.2.5/VALIDATION.md)。

## English

Download **`photocraft-codex-ai-0.2.5.zip`**, extract the entire archive into a writable folder, and double-click **`start.cmd`**. Save your documents and close the previous version before updating.

- Edit selections, remove objects, and generate images directly from the toolbar below the PhotoCraft selection.
- Image generation no longer adds edge feathering, preserving the original selection mask. Selection edits and object removal retain the default 12 px inward feathering.
- Supports a separate HTTP proxy for Codex processes launched by the plugin, with HTTPS transport and limited connection retries.
- Results are added as new layers with Ctrl+Z undo support.
- This version requires Python 3.10+, Pillow (`pip install -r requirements.txt`), and an installed, signed-in Codex CLI with working built-in image generation. No API key is required, and there is no automatic paid API fallback.

This is a Windows x64 preview development build. Internet access and a Codex account with working built-in image generation are required. GitHub's automatically generated Source code archives do not include the matching editor binary. See [VALIDATION.md](https://github.com/kaliwell/photocraft-codex-ai/blob/v0.2.5/VALIDATION.md) for recorded results and known boundaries.
